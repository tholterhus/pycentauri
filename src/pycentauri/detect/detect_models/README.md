Trained spaghetti models bundled for out-of-the-box detection.

- `spaghetti_edgetpu.tflite` — Coral variant (99/102 ops on the chip)
- `spaghetti.tflite` — int8 CPU sibling (auto-loaded without a Coral)
- `spaghetti.txt` — label file
